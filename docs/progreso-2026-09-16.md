# Progreso del proyecto - 2026-09-16

## Resumen

Se revisó el SDK de Pulso TransMi, se analizaron los datos publicados por el API,
se generaron visualizaciones exploratorias y se preparó la persistencia para ML
en un proyecto nuevo de Supabase.

## API y repositorio

- Se clonó el repositorio `uexternadojz/pulso-transmi-sdk`.
- Se verificó que el API responde correctamente con `GET /v1/meta` y estado HTTP 200.
- El API corresponde a la versión `0.2.0` y publica datos sintéticos de demanda,
  contexto climático y estaciones.
- El periodo disponible analizado fue del 26 de julio al 8 de septiembre de 2026.

## Análisis exploratorio

Se analizaron temporalmente los archivos públicos `stations.csv`,
`observations.csv` y `context.csv` sin agregar código de análisis al proyecto.

Hallazgos principales:

- 12 estaciones, 51.840 observaciones y 4.320 registros de contexto.
- Cada estación tiene 4.320 observaciones.
- No se encontraron valores nulos ni duplicados.
- La demanda tiene media 356,52 y mediana 263, con distribución asimétrica.
- Los picos principales ocurren alrededor de 06:45-07:15 y 17:15-18:15.
- La demanda baja durante la madrugada y los fines de semana.
- La autocorrelación a 15 minutos es alta, entre 0,92 y 0,95 según la estación.
- La temperatura mostró una relación moderada con la demanda; la lluvia tuvo una
  relación lineal prácticamente nula.
- Ricaurte - NQS presentó la mayor demanda media, mientras que Portal Usme tuvo
  la menor.

## Supabase y modelo de datos

Se creó la migración:

- `supabase/migrations/20260916120000_initial_ml_schema.sql`

La migración crea el esquema `pulso` con tablas para:

- `stations`, `observations` y `context`.
- `data_cutoffs` y `feature_snapshots`.
- `model_versions`, `training_runs` y `predictions`.
- `data_quality_checks` y `drift_reports`.

También incluye claves foráneas, restricciones de calidad, índices, RLS y la
vista `pulso.prediction_evaluation` para comparar predicciones con observaciones
reales cuando estén disponibles.

Se añadió la guía [supabase/README.md](../supabase/README.md) con instrucciones
para enlazar y aplicar la migración.
