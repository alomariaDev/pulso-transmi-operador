Pipeline de Inferencia & Submissions

  • 1 Cron cada 10 min en GitHub Actions consulta GET /v1/forecast-cycles/current.
  • 2 Si hay ciclo abierto, sincroniza datos de demanda y clima.
  • 3 Genera features (rezagos de 15m, 24h, 7d y ventanas móviles).
  • 4 Envía predicciones por POST /v1/submissions con clave de idempotencia.

Persistencia & Base de Datos

  • Esquema: pulso (PostgreSQL)
  • Tablas Principales: stations, observations, context
  • Trazabilidad ML: model_versions, drift_reports
  • Frecuencia Colector: 1 hora (Automático)
